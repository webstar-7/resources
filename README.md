# NYANSATEK Resources

One page for every NYANSATEK tool: https://webstar-7.github.io/resources/

| Tab | Tool | Own site |
|---|---|---|
| Passport | Passport Photo Studio | https://webstar-7.github.io/passport/ |
| Fullbody | Full-Body Photo Studio | https://webstar-7.github.io/fullbody/ |
| Video Editor | NYANSATEK Video Studio | https://webstar-7.github.io/veditor/ |
| Graphic Studio | Nyansatek Studio | https://webstar-7.github.io/studio/ |
| Beat | Beat maker and Frequency Lab | https://webstar-7.github.io/beat/ |

Each tab opens the tool inside the page and keeps it loaded while you switch tabs. "Open on its own" opens the tool's own site, where it can be installed as an app. Tabs can be linked directly, e.g. `/resources/#video-editor`.

To add a tool, add one entry to the `TOOLS` list in `index.html`.
